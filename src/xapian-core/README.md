## how to install

```shell
# for dev
sudo dnf --disablerepo='*' --enablerepo=copr:copr.fedorainfracloud.org:ttys3:my-fedora-packages reinstall xapian-core xapian-core-devel xapian-core-libs

# for debug
sudo dnf --disablerepo='*' --enablerepo=copr:copr.fedorainfracloud.org:ttys3:my-fedora-packages reinstall xapian-core-debuginfo xapian-core-debugsource xapian-core-libs-debuginfo
```

## how to build

```shell
# fetch the upstream tarball and its signature
spectool -g xapian-core.spec

# local mock build; fedpkg skips the lookaside download when the local files match `sources`
./build.sh
```

## notes

All of the following was checked against the 2.1.0 release tarball and a Fedora 44 mock build.

- 2.x is the upstream stable series (2.1.0 is the latest stable release). The
  development-series suffix logic in `configure.ac` now only matches `1.[13].*`,
  so there is no `-1.5` style suffix any more: headers are `/usr/include/xapian.h`
  and `/usr/include/xapian/*.h`, the pkg-config module is `xapian-core`, and the
  programs are installed without a version suffix.
- soname: 2.0.0 is `LIBRARY_VERSION_INFO=45:0:0` and 2.1.0 is `46:0:1`, so both
  ship `libxapian.so.45`; binaries built against 2.0.0 keep working with 2.1.0.
- ICU: `FLAG_WORD_BREAKS` (UAX#29 word segmentation, needed for CJK text)
  requires ICU. `configure` only auto-detects it via `pkg-config icu-uc >= 54.1`
  and has no switch to force it, so the spec BuildRequires `pkgconfig(icu-uc)`
  and fails the build when `USE_ICU` is missing from `config.h`. Check a built
  package with `rpm -qp --requires xapian-core-libs-*.rpm | grep icu`.
- The upstream tarball signature is verified in `%prep` with Olly Betts' key
  `08E2400FF7FE8FEDE3ACB52818147B073BAD2B07`, cross-checked against Debian's
  `debian/upstream/signing-key.asc` and keys.openpgp.org.
- The official tarball ships API docs generated by Doxygen 1.15.0, including
  `dynsections.js`, so it is used as-is.

## troubleshoot

Fedora's own `xapian-core-libs` is the 1.4 series (`libxapian.so.30`). This 2.x
build can only replace it when no installed package needs `libxapian.so.30`;
on Fedora 44 those include doxygen, notmuch, recoll, dovecot, akonadi-search,
khelpcenter and libzim:

```shell
dnf repoquery --whatrequires 'libxapian.so.30()(64bit)'
```

doxygen links libxapian for its external search tools (`doxyindexer` / `doxysearch.cgi`);
`../doxygen` in this repo is Fedora's doxygen rebuilt against xapian 2.x:

https://src.fedoraproject.org/rpms/doxygen/blob/rawhide/f/doxygen.spec

https://www.doxygen.nl/manual/extsearch.html
